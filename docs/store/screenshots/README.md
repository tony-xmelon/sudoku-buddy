# Play Store screenshots

Captured from the release-signed build 1.0.0 (116) on a physical Android phone on
8 September 2026. All five submission images are unaltered 1080 x 1920 PNG screenshots.

1. `01-scan.png` — live camera view with a full handwritten Sudoku inside the capture guide
   and the detected grid outlined in green.
2. `02-puzzle.png` — recognized photographed puzzle with handwritten entries and recognition
   confidence markers.
3. `03-check.png` — the app's Check view, with translucent green correct cells and a red
   incorrect handwritten digit.
4. `04-hint.png` — a completed Naked single hint identifying the target square and answer.
5. `05-history.png` — on-device puzzle history, including in-progress and completed scans.

Use these Play Console alt-text descriptions:

1. `01-scan.png` — Camera view detecting a full handwritten Sudoku inside the capture frame.
2. `02-puzzle.png` — Recognized photographed Sudoku ready to be checked or corrected.
3. `03-check.png` — Check view marking correct handwritten digits green and one incorrect
   digit red.
4. `04-hint.png` — Naked single hint highlighting the answer in the photographed Sudoku.
5. `05-history.png` — On-device history of previously scanned Sudoku puzzles.

The `raw` directory contains source captures, recordings, contact sheets, and rejected frames;
do not upload it to Play Console. Only the five numbered PNG files above are submission-ready.
