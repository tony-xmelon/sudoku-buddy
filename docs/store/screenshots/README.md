# Play Store screenshot shot list

Capture these from a real phone after installing the Play-signed or release-signed build.
Use a clean printed puzzle with no personal material visible in the camera background.

1. `01-scan.png` — the camera framing a printed Sudoku, with the complete grid visible and
   the app's capture guidance readable.
2. `02-puzzle.png` — the correctly recognized puzzle before a hint is applied.
3. `03-explained-hint.png` — a visually useful hint with its highlighted cells and plain-
   language explanation visible.
4. `04-history.png` — optional, showing that a scanned puzzle can be reopened.

Use these Play Console alt-text descriptions:

1. `01-scan.png` — Camera view framing a printed Sudoku grid for scanning.
2. `02-puzzle.png` — Recognized Sudoku board ready for corrections and solving.
3. `03-explained-hint.png` — Step-by-step Sudoku hint with highlighted cells and an explanation.
4. `04-history.png` — On-device history of previously scanned Sudoku puzzles.

Export portrait images at 1080×1920 or another 9:16 size. Do not include notifications,
personal photographs, device identifiers, or unrelated apps in the status area. Check every
recognized digit before taking the screenshots so the listing does not advertise a mistake.
Keep the images as unaltered app screenshots. The interface is strong enough to stand on its
own, and avoiding promotional text overlays means one English set remains usable globally.
